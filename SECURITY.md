# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through **GitHub private vulnerability reporting** (Security tab → "Report a vulnerability" on this repository) — never through a public issue. A public reproduction is a working exploit handed to everyone.

This is a solo hobby project: reports are read on a best-effort basis, typically within a couple of weeks. No response-time SLA is promised.

## Security findings register

Security findings from this project's own audits are tracked as public issues under the `security` label, with severity (`sev:*`) labels. noteapi is a local, single-user tool, so transparent tracking helps anyone running it assess risk.
